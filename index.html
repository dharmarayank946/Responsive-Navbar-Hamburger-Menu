VEDA Technology Internship • Task 21

Responsive Navbar with Hamburger Menu

A modern, accessible, and high-performance navigation component engineered strictly with HTML5, CSS3, and Vanilla JavaScript. Featuring a mobile-first responsive layout, smooth slide transitions, keyboard accessibility, and a light pastel green design aesthetic.

Learn About Task Explore Features

Horizontal Desktop Bar

Clean horizontal list with subtle hover effects and active state indicator for large screens.

Animated Hamburger

Smooth 3-bar into 'X' transformation indicating open/closed state on mobile viewports (≤ 768px).

WAI-ARIA Accessible

Complete keyboard navigation support, focus visible rings, Escape key closing, and ARIA attributes.

About The Project

Clean Engineering & Design Architecture

Engineered to fulfill all 10 core requirements of VEDA Technology Web Development Internship Task 21.

1. Semantic Structure

Utilizes semantic HTML5 elements including <header>, <nav>, <button>, and <ul> with appropriate ARIA roles to ensure universal screen reader compatibility.

2. classList.toggle() State

Navigation drawer toggling is managed using vanilla JavaScript's classList.toggle('is-active'), keeping the DOM logic clean, performant, and beginner-friendly.

3. Slide Transitions

Uses hardware-accelerated CSS transform: translateX() transitions for silky 60fps sliding without layout repaints or jank.

4. Auto-Closing & Escape Key

The mobile navigation collapses automatically when any link is selected, when clicking the backdrop overlay, or when the user presses the Esc key.

Services

Responsive Design Disciplines

Core responsive web practices demonstrated within this lightweight implementation.

01

Mobile-First Media Queries

The stylesheet establishes responsive breakpoints using standard CSS media queries at 768px, gracefully scaling from compact smartphones to ultra-wide desktop monitors.

02

Touch Target Optimization

Every navigation link and hamburger toggle satisfies accessibility guidelines with minimum 44×44px touch boundaries for effortless mobile interaction.

03

Light Pastel Green Color Harmony

Carefully selected tokens adhering to WCAG AAA contrast: `#2D6A4F` deep sage primary green, `#EAF5EE` mint badge background, and `#1C2B21` high-contrast dark green text.
